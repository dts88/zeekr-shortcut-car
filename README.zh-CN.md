# 极氪即刻（车机版）

面向极氪 7X 车机的环视记录仪。

[English](README.md) · [更新日志](CHANGELOG.md) · [来源与致谢](NOTICE.md) · [平台笔记](docs/zeekr-platform-notes.md)

> [!IMPORTANT]
> **已知问题：每天用后座舱摄像头录制，最终可能让 App Lab 崩溃，需要重新安装。** 原因仍在排查，日常录制建议只用环视；如果录了后座舱，离车前请点设置页底部的「退出应用」。如遇此问题，或出现应用异常卡顿、摄像头画面无法获取，请**在重启车机前**于「设置 → 系统 → 诊断信息」导出诊断报告，并通过 [GitHub](https://github.com/dts88/zeekr-shortcut-car/issues) 等渠道反馈。给您带来不便，深表歉意。

## 这是什么

极氪 App Lab 只把四路环视以**一路拼接好的合成流**开放给第三方应用——四个方形画面挤在同一帧里，
直接预览是一根比例失真的竖条。本应用把它拆回 2×2 四宫格，并在此之上做了下面这些。
界面有中文、English、Bahasa Melayu 三种。

### 行车记录

- 环视按四宫格录制；打开前座舱、后座舱后，这两路一起录。
- **录制声音**（默认开启）：环视录像同步录下车内外的声音，回放时可以听到。
- 三档录制画质：省空间（10 fps）、均衡（20 fps）、最清晰。每一档都先写明每小时占多少 GB、
  这张 U 盘能录多久。帧率、码率、分段时长、编码也可以按路单独调。
- 1–10 分钟自动分段。设了录像存储上限，超出上限或剩余空间不足时自动清理最旧的未锁定录像；
  没设上限，不删任何录像，空间不足时停止录制。
- **锁定影像**：锁定的录像和照片不会被循环录制清除。悬浮按钮可一键锁定当前录像，
  闪远光、打双闪时也可自动锁定。
- 拍照用每一路的最大尺寸。
- **只录到外置 U 盘**。写内置存储需要先解锁开发者选项——车机闪存换不了，持续写入是在消耗它的寿命。
- **行驶信息条**（试验性，默认关闭）：把转向灯、方向盘、档位、踏板、车速、灯光等车辆状态，
  录在画面下方的一条里。显示内容可自选。

主界面上点任意一路画面，它就铺满预览区，再点一下还原。「鱼眼校正」按钮把弯曲的画面拉直，
主界面和回放里都能用。悬浮按钮在任何界面都显示是否正在录，
点一下回到应用。

### 超级镜子

电子后视镜：可停靠的悬浮窗，把任意一路单独放大。捏合缩放，左右划换一路，中间三分之一上下滑调取景高低。
也可以把「切换方式」设为「点按切换」，点窗口的上、下、左、右切换摄像头。
「切换范围」可以只在前后之间，或后视和后座舱之间切换。
推出屏幕一半即贴边隐藏，点一下就回来。后视那一路做左右镜像，与真实后视镜一致。
鱼眼校正与视野角度可选。

### 盲区画面

打转向灯时，在屏幕该侧显示侧方摄像头的画面，可显示在中控屏、HUD 或两处同时显示。默认关闭。
仅作辅助，请注意驾驶安全。

### 回放

录像回放同时显示所有摄像头，按时间同步播放；点任意一路放大，再点返回。照片回放布局相同。

### 快速分享至手机

在看某张照片或某段录像时点「发送到手机」：车机显示一个二维码，手机扫码后浏览器直接打开这个文件，
长按保存。手机上不用装任何东西。

文件只在这个对话框开着的时候通过局域网提供，地址是一次性的随机串，而且只有这一个文件。
两台设备需要在同一个网络里——最省事的做法是用手机开热点，让车机连上。

### 试验性功能

- **灵动贴**：可以连接名为 `ZEEKR_button` 的蓝牙按钮，单击、双击各设一个动作：悬浮按钮能做的全部动作，
  或切换驾驶模式。设置里显示每个灵动贴的电量。
- **模拟声浪**：运动模式下播放模拟发动机声，随油门和车速变化，有美式 V8 和超音速两种声音，
  标准模式下也可播放。有时没有声音，目前看只在收音机或 CarPlay 播放时才出声。

## 安装

**开始之前**：你需要事先知道怎么通过 App Lab 把应用侧载到车机上，本页不介绍这一步。

- **推荐 —— [Releases](../../releases) 页面上最新的 `-beta`。** 装好之后，应用可以在
  设置 → 检查更新 里自己取后续的 Beta 版。
- [最新正式版](../../releases/latest)版本较旧，没有本页介绍的部分新功能。

在发布页下载 `ZeekrShortcut-*.apk`，通过 App Lab 侧载安装。安装完成后请点左上角「返回」，
不要点「打开」，否则车机安装器会卡住，之后的安装或更新会失败。

自行构建需要 JDK 17+ 与 Android SDK（compileSdk 36）：

```bash
git clone https://github.com/dts88/zeekr-shortcut-car.git
cd zeekr-shortcut-car && ./gradlew assembleRelease
```

仓库内含一个公开的 AOSP 测试签名密钥（口令 `android`），正式发布请用自己的密钥覆盖：
`ZEEKR_KEYSTORE`、`ZEEKR_KEYSTORE_PASSWORD`、`ZEEKR_KEY_ALIAS`、`ZEEKR_KEY_PASSWORD`。

## 推荐

**[Zeekr Companion](https://github.com/wysie/zeekr-shortcut-car)**：wysie 针对极氪 009 车机优化的极氪即刻版本。Wysie 也是提供了大量极氪基础信息的重要贡献者，很开心能与 Wysie 一同探索极氪车机系统的可能性。

**[CAMCORDER](https://github.com/FerixzTanz/CAMCORDER)**：FerixzTanz 在极氪即刻基础上开发的版本，有一系列领先于极氪即刻的功能。本项目的盲区画面起步于 FerixzTanz 的代码和实车研究；把盲区画面投到抬头显示（HUD）上的做法、HUD 的设置和他细致的实车标定，也来自 CAMCORDER。感谢 FerixzTanz 对本项目的支持和贡献。

**[CarPiano](https://github.com/jlunnn/CarPiano)**：任何车速下都能用车外喇叭播放声音，不再像原车功能那样只能在 P 挡使用。目前还在早期开发阶段，但很值得期待。

在公共道路上使用车外喇叭前，请先了解当地法规。

## 已知限制

- **只针对极氪 7X 设计**。只有被认出是合成流的那一路才拆分；车机没有提供合成流时，一路都不拆。
- **原厂功能优先**：原厂 360° 环视、倒车影像、泊车相机可能随时收回相机资源。
- **启动自动录制默认关着**。开启哨兵模式时，熄屏后继续录制环视，后座舱亮屏后恢复录制；未开启时，熄屏后暂停录制，亮屏后恢复。
- **前座舱摄像头目前是一次性的**：离车时自动关闭。
- **环视画面的裁剪暂时停用**。
- **实车验证仍在进行**：自动化测试只覆盖纯逻辑部分，首次使用请在静止车辆上测试。
