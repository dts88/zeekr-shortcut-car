# 极氪即刻（车机版）

让极氪 7X 车机用上车上自带的环视摄像头：当行车记录仪录下来，开车时在需要的地方显示出来。

## 这是什么

通过 App Lab，第三方应用拿到的 7X 四路环视是一路拼接好的画面，直接预览是一根比例失真的竖条。
极氪即刻把它拆回四路画面，并在此之上做了这些：

- **行车记录**：录制环视画面，打开座舱摄像头后一起录，存到 U 盘。
- **超级镜子**：悬浮的电子后视镜，把任意一路单独放大。
- **盲区画面**：打转向灯时，在中控屏或 HUD 上显示该侧的侧方画面。
- **回放**：所有摄像头同步回放；照片或录像可以发送到手机。

全部功能、设置和使用提示见 **[wiki](../../wiki)**。

## 下载

在 **[Releases](../../releases/latest)** 下载 APK。装好之后，应用可以自己检查新版本：设置 → 更新与关于 → 检查更新。

- 你需要事先知道怎么通过 App Lab 把应用侧载到车机上，本页不介绍这一步。
- 安装完成后请点左上角「返回」，不要点「打开」，否则车机安装器会卡住，之后的安装或更新会失败。

从源码构建：见 [wiki](../../wiki/%E4%BB%8E%E6%BA%90%E7%A0%81%E6%9E%84%E5%BB%BA)。

提问和建议：[讨论区](../../discussions)。遇到问题：[提交 issue](../../issues)，并附上「设置 → 通用 → 诊断信息」导出的报告。

## 推荐

**[Zeekr Companion](https://github.com/wysie/zeekr-shortcut-car)**：wysie 针对极氪 009 车机优化的极氪即刻版本。Wysie 也是提供了大量极氪基础信息的重要贡献者，很开心能与 Wysie 一同探索极氪车机系统的可能性。

**[CAMCORDER](https://github.com/FerixzTanz/CAMCORDER)**：FerixzTanz 在极氪即刻基础上开发的版本，有一系列领先于极氪即刻的功能。本项目的盲区画面起步于 FerixzTanz 的代码和实车研究；把盲区画面投到抬头显示（HUD）上的做法、HUD 的设置和他细致的实车标定，也来自 CAMCORDER。感谢 FerixzTanz 对本项目的支持和贡献。

**[CarPiano](https://github.com/jlunnn/CarPiano)**：任何车速下都能用车外喇叭播放声音，不再像原车功能那样只能在 P 挡使用。目前还在早期开发阶段，但很值得期待。

在公共道路上使用车外喇叭前，请先了解当地法规。

## 来源与许可证

**GPL-3.0**，继承自 [EVCam](https://github.com/suyunkai/EVCam)（作者 suyunkai）——本应用的代码基座。
本仓库第一个 commit 就是 EVCam 的完整工作树，此后所有改动均以 diff 可见。
按 GPL-3.0 要求，本应用同样以 GPL-3.0 发布并公开全部源代码。

把 App Lab 的合成流拆成四宫格并渲染出来，是本项目独立实现的。

模拟声浪的合成方法、各款声音和调校，都是 dts88 的原创；CarPiano 和 EngineV1 只提供了事实（见 [NOTICE.md](NOTICE.md)）。

### 贡献者

- **[wysie](https://github.com/wysie)**：大量设计以及代码。
- **[FerixzTanz](https://github.com/FerixzTanz)**：盲区画面的最初代码和实车研究，以及把盲区画面投到 HUD 上的做法（来自他的 CAMCORDER）。
  盲区画面默认的角度和窗口大小、HUD 上画面的默认设置，都是他在自己的 7X 上实车调出来的，非常感谢他细致的参数调整。
- **[jlunnn](https://github.com/jlunnn)**：灵动贴的「后雾灯闪烁」动作（来自他的 7X-U），以及让单元测试在 Windows 上也能通过的修正。
  也是 CarPiano 的作者。
- **[calvinbui](https://github.com/calvinbui)**：在他的澳洲 7X 上实测空调、驾驶和安全相关的设置，并整理成文档。
- **[lelelolo](https://github.com/lelelolo)**：盲区画面的两处改进：车机占用摄像头时不再显示黑框；后视镜上的灯亮着时，画面描一圈同色的边框。非常感谢。
- **SW**：积极测试和反馈，非常感谢。

来源、第三方组件许可与边界说明见 [NOTICE.md](NOTICE.md)，完整条款见 [LICENSE](LICENSE)。
