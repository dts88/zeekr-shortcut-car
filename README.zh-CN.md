## 这是什么

极氪 App Lab 只把四路环视以**一路拼接好的合成流**开放给第三方应用——四个 1280×1280 的方形画面
挤在同一帧里，直接预览是一根比例失真的竖条。本应用把它正确拆回 2×2 四宫格，并在此之上做了三件事。

### 1. 环视行车记录

四路同时录。H.264 / H.265，1–10 分钟自动分段，容量满了自动清理最旧的文件；帧率、码率、
落盘排列（四宫格或原始长条）可调。开机自启，息屏和锁车后继续录。

**只录到外置 U 盘**。写内置存储需要先解锁开发者选项——车机闪存换不了，持续写入是在消耗它的寿命。

### 2. 电子后视镜

可停靠的悬浮窗，把任意一路单独放大。捏合缩放，左右划换一路，中间三分之一上下滑调取景高低；
鱼眼校正与视野角度可调，窗口拉成任意宽高而画面比例不变。推出屏幕一半即贴边隐藏，点一下就回来。
后视那一路做左右镜像，与真实后视镜一致。

### 3. 快速分享至手机

在看某张照片或某段录像时点「发送到手机」：车机显示一个二维码，手机扫码后浏览器直接打开这个文件，
长按保存。手机上不用装任何东西。

文件只在这个对话框开着的时候通过局域网提供，地址是一次性的随机串，而且只有这一个文件。
两台设备需要在同一个网络里——最省事的做法是用手机开热点，让车机连上。

## 安装

从 [Releases](../../releases) 下载 `ZeekrShortcut-*.apk`，通过 App Lab 侧载安装。

装好后进入 **设置 → 录制 → 视频流配置**，选择「极氪7X（环视合成流）」并按提示重启应用。
若提示未检测到合成流，说明该车机 / 固件版本的 Camera2 没有声明合成流尺寸，本应用不适用。

自行构建需要 JDK 17+ 与 Android SDK（compileSdk 36）：

```bash
git clone https://github.com/dts88/zeekr-shortcut-car.git
cd zeekr-shortcut-car && ./gradlew assembleRelease
```

仓库内含一个公开的 AOSP 测试签名密钥（口令 `android`），正式发布请用自己的密钥覆盖：
`ZEEKR_KEYSTORE`、`ZEEKR_KEYSTORE_PASSWORD`、`ZEEKR_KEY_ALIAS`、`ZEEKR_KEY_PASSWORD`。

## 已知限制

- **只针对极氪 7X 的合成流格式设计**。其他车型或固件版本若排布不同，会走等分回退，画面可能偏移。
- **原厂功能优先**：原厂 360° 环视、倒车影像、泊车相机可能随时收回相机资源，本应用应让路。
- **落盘量大**：约 200 MB/min 持续写入，这也是默认录到 U 盘的原因。
- **实车验证仍在进行**：自动化测试只覆盖纯逻辑部分（几何拆分、相机选择、手势模型），
  取流与录制链路需要实车验证，首次使用请在静止车辆上测试。
