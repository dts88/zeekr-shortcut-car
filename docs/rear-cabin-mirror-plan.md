# 后座常驻画面 · 计划（下一个大版本）

记录于 2026-09-27（当时的版本：1.53.0-alpha）。还没开始做，这里只记要什么、不要什么。

## 要什么

一个**常驻显示后座画面**的悬浮窗，画面来自后座舱那一路相机（配置里的角色 `cabin2`），
方便开车时看后排。它基本是[超级后视镜](rearview-gesture-spec.md)的简化版。

| | 超级后视镜 | 后座常驻画面 |
|---|---|---|
| 画面来源 | 环视合成流里的任一路 | 后座舱相机 |
| 鱼眼校正 | 有 | **没有**：座舱镜头本来就不是鱼眼 |
| 左右划换一路（4.4） | 有 | **没有**：只有这一路 |
| 上下滑调取景（4.3） | 有 | **没有**（已确认） |
| 缩放 | 宽、高各自可调 | **只整体按比例放大缩小**，宽高比锁死 |
| 左右镜像 | 固定：「后」那一路镜像 | **有一个按钮**，用户自己切换 |
| 画面停了 → 盖住，写「点击恢复」（4.6） | 有 | **有**：安全要求，理由相同 |

## 待定

- 拖动、贴边收起、取回（超级后视镜 4.1、4.2）要不要照搬。
- 镜像按钮放在哪：超级后视镜整个窗口都是手势区、没有按钮，这里要给按钮留位置。
- 镜像状态要不要记住，下次启动沿用。
- 后座舱相机只在「极氪7X（环视 + 前后座舱）」配置下开着。在只开环视的配置下怎么办：
  不显示这个开关，还是打开它时顺带开这一路。
- 和超级后视镜能不能同时开。
