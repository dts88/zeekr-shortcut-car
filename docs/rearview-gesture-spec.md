# 超级后视镜 · 操作规则与形状（给设计用）

这份文档是画「首次开启时的操作说明图」的依据。全部规则和数字都来自
`RearViewTouchModel` / `RearViewMirrorView` / `LaneCycle`，不是设想。

---

## 1. 它是什么

一个**可拖动、可缩放、可停靠的悬浮窗**，把环视合成流里的**任意一路**单独放大。
主界面在不在前台都不影响它，录制、预览、回放也都不受它影响。

默认关闭。开启后随应用启动自动出现（相机开好后延迟 2 秒）。

---

## 2. 形状

```
        ┌──────────────────────────────┐
        │                              │
        │        画面（保持比例）        │   ← 窗口可拉成任意宽高
        │                              │      画面比例永远不变
        └──────────────────────────────┘
```

- **窗口尺寸**：宽、高各自可调，范围从 **120 px** 到整块屏幕（宽到屏幕宽、高到屏幕高）。
- **画面比例锁死**：窗口形状决定**看到多大一块**，不决定画面被拉成什么样。
  框拉扁 → 看到的是一条横向的带；框拉高 → 看到更完整的一幅。画面本身不会变形。
- **无边框、无标题栏、无按钮**。整个窗口就是画面，所有操作都是手势。
- 停靠后只露出 **72 px** 宽的一条边。

---

## 3. 手势分区

窗口横向分三段，**按下时落在哪一段，这一次操作就归哪一段管**：

```
   ┌─────────┬─────────┬─────────┐
   │  左 1/3  │  中 1/3  │  右 1/3  │
   │         │         │         │
   │  拖动    │  上下滑  │  拖动    │
   │  窗口    │  调取景  │  窗口    │
   │         │  左右划  │         │
   │         │  换一路  │         │
   └─────────┴─────────┴─────────┘
```

**双指缩放不分区**，落在窗口任何位置都有效。

---

## 4. 逐条规则

### 4.1 拖动窗口（左 1/3 或右 1/3，单指）

- 拖动距离超过 **12 px** 才算开始拖，以内视为点击。
- 松手后**只有三种落点**，不会停在中间：
  1. **贴边隐藏** —— 窗口被推出屏幕**一半以上**，或朝那条边**甩**了一下且窗口已压到边上；
  2. **整个收回屏幕内** —— 推出去了但没到一半；
  3. **原样贴回** —— 本来就贴着边，这一下没拉够。

> 判据是「推出去了多少」，不是「离边缘多近」。窗口只要还完整在屏幕里，一定不会被吸走。

### 4.2 取回贴边的窗口

两种任选其一：

- **点一下** —— 贴边后屏幕上只剩一条窄边，点它就回来；
- **往屏幕里拉 60 px**，或往里**甩**一下。

回来的落点是**贴着刚才藏进去的那条边、整个滑进屏幕**（不是回到贴边前的位置）。
滑回的动画时长随甩动速度变化，甩得越快回得越快。

> 推出去要够狠（一半宽度），拿回来只要 60 px —— 门槛是**故意不对称**的。
> 藏错了拿不回来是死结，多滑一次只是麻烦。

### 4.3 调取景高低（中 1/3，单指上下滑）

- 手指**往下**拖 → 看画面**上方**的内容（方向是反的，和拖动纸张一致）。
- 手指划过整个窗口高度 = 取景从最上挪到最下。
- 窗口是正方形时整幅都看得见，**没有可挪的余地**，这一下不产生任何变化。

### 4.4 换一路（中 1/3，单指左右划）

- **右滑 = 顺时针**：后 → 左 → 前 → 右 → 后
- **左滑 = 逆时针**：后 → 右 → 前 → 左 → 后
- 触发门槛：横向划**满 90 px**，或者**甩**一下（甩的方向必须和位移方向一致）。
- 方向在起手时就锁定：横向意图（|dx| > |dy|）锁为换路，此后竖直位移不会让取景抖动。
- 开了「只显示前后视」时，环只剩 **后 ↔ 前** 两档。

### 4.5 缩放（双指，任意位置）

- 以**两指中点为锚**：按下时锚点落在窗口的哪个相对位置，之后就一直待在两指中点底下。
- 因此「以触点为中心缩放」和「两指拖着走」是同一个动作，可以同时发生。
- 缩放倍数整体夹紧，**宽高比不会因为撞到屏幕边而被压变形**。

---

## 5. 镜像

**只有「后」这一路做左右镜像**，和真实后视镜一致。前、左、右三路不翻。

镜像只作用于这个悬浮窗，**预览、录制、回放都不受影响**。

---

## 6. 说明图想覆盖的最小集合

如果只能画一张图，按重要性排：

1. **三分区**（左右拖窗口 / 中间调取景 + 换路）—— 不知道这条就等于没法用
2. **左右划换一路的方向**（右滑顺时针 后左前右）
3. **贴边隐藏与取回**（推出一半 → 藏；点一下 → 回来）
4. **双指缩放**
5. 后视一路是镜像的

---

## 7. 视觉风格参考

应用整体是 **Material 3 深色**，设置界面为浅色卡片风格。

| 用途 | 色值 |
|---|---|
| 主色 / 强调 | `#4A90D9` |
| 深色背景 | `#1A1A1A` |
| 深色卡片面 | `#2A2A2A` |
| 浅色页面背景 | `#D4DBE6` |
| 浅色卡片 | `#F9FAFB` |
| 主要文字（浅底） | `#1A1A1A` |
| 次要文字（浅底） | `#666666` |
| 深底上的文字 | `#FFFFFF` |

字体使用系统默认（车机为思源黑体一类），不引入外部字体。

**版面约束**：车机屏幕是横置的，内置屏约 3200 px 宽。说明图会在悬浮窗开启时弹出，
应当**一屏看完、不需要滚动**，且**不能挡住行车视线区域**——建议横向构图，
高度不超过屏幕的一半。
